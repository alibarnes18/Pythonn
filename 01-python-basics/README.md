# 01 — Python Temelleri

Girdi/çıktı, koşullar, döngüler ve temel veri yapıları üzerine alıştırmalar.

## Dosyalar

| Dosya | Açıklama | Kavramlar |
|-------|----------|-----------|
| `calculator.py` | İki sayı ile dört işlem (+, -, *, /) | `input`, `if/elif`, sıfıra bölme kontrolü |
| `number_guessing.py` | 1–100 arası sayı tahmin oyunu | `random`, `while`, `try/except` |
| `number_guessing_v2.py` | Geliştirilmiş tahmin oyunu | Deneme limiti, tekrar oynama |
| `port_list_exercise.py` | Tehlikeli port listesi alıştırması | `list`, `for`, `append`, `in` |
| `port_list_exercise_v2.py` | Aynı alıştırmanın alternatif sürümü | Liste işlemleri |
| `rpg_character_creator.py` | RPG karakter oluşturucu (FCC projesi) | Fonksiyon, doğrulama, string formatlama |

## Çalıştırma

```bash
python calculator.py
python number_guessing.py
python rpg_character_creator.py
```

## Öğrenme Hedefleri

- Kullanıcıdan veri almak ve sonuç yazdırmak
- Koşullu dallanma ve döngü mantığı
- Hata durumlarını ele almak (ör. sıfıra bölme, geçersiz giriş)
